# Общий доступ к библиотеке рецептов

Функция позволяет владельцу открыть другому зарегистрированному пользователю доступ
**только на просмотр** своих рецептов. Гость может искать, открывать, делиться рецептом
и создать его личную копию в своей библиотеке.

## 1. Применить миграцию базы

1. Откройте Supabase Dashboard → **SQL Editor** → **New query**.
2. Скопируйте всё содержимое файла `supabase/migrations/20260901_shared_recipe_library.sql`.
3. Нажмите **Run**.

Скрипт создаёт:

| Объект | Назначение |
|---|---|
| `public.profiles` | Персональный код доступа пользователя |
| `public.recipe_library_access` | Кто кому выдал доступ |
| Политика `Viewers can read shared recipes` | Право `SELECT` на рецепты владельца |
| `get_my_share_code()` | Возвращает или создаёт мой код |
| `grant_library_access_by_code(p_code)` | Выдаёт доступ по коду |
| `list_library_access()` | Кому я выдал доступ |
| `list_shared_with_me()` | Кто выдал доступ мне |
| `revoke_library_access(p_viewer_id)` | Отзыв доступа |

Права `INSERT`, `UPDATE` и `DELETE` на чужие рецепты не выдаются: существующие
политики владельца не изменяются.

## 2. Опубликовать сайт

Файл `index.html` обновляется автоматически, если репозиторий подключён к Netlify.
Иначе загрузите `index.html` вручную через **Deploys → Deploy manually**.

## 3. Как пользоваться

### Гость

1. Регистрируется в приложении.
2. Открывает **Профиль** → видит «Мой код доступа».
3. Нажимает **Копировать** и присылает код владельцу.

### Владелец

1. Открывает **Доступ**.
2. Вставляет код и нажимает **Выдать доступ**.
3. В списке «Пользователи с доступом» может нажать **Отозвать**.

### Результат

У гостя в библиотеке появляется вкладка **«Доступные мне»**. Карточки помечены
меткой «Только просмотр», кнопок «Править» и «Удалить» у них нет. В карточке и в
окне рецепта доступна кнопка **«Скопировать к себе»** — она создаёт новый рецепт с
`user_id` гостя. Оригинал остаётся неизменным, «избранное» не переносится, а в
личную заметку копии добавляется строка вида
`Скопировано из общей библиотеки 01.09.2026`.

## Проверка

1. Войдите вторым аккаунтом в другом браузере и скопируйте его код из «Профиля».
2. Первым аккаунтом выдайте доступ по этому коду.
3. Обновите страницу вторым аккаунтом и откройте вкладку «Доступные мне».
4. Убедитесь, что рецепты видны, а кнопки редактирования отсутствуют.
5. Нажмите «Скопировать к себе» и проверьте копию во вкладке «Мои рецепты».
6. Первым аккаунтом нажмите «Отозвать» — вкладка «Доступные мне» у гостя опустеет.
